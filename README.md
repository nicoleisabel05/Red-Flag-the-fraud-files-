# Red-Flag-the-fraud-files-
The dataset: 200,000 transactions from a simulated Indian payment aggregator. The mission: catch 12 different fraud patterns hidden in the data. Patterns I detected:  Velocity fraud Card testing Money laundering Mule accounts  Structuring at just-under-KYC-threshold Rs 9999 Account takeover via velocity spike + geographic impossibility.
Used SQL queries, aggregations, joins, CTEs, and window functions to detect potentially fraudulent users and transaction patterns.
